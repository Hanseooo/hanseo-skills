# Stress Test — Jev-Like New Technology

## Input

> A new low-latency structured AI decision primitive launched. What products could it enable?

## Failure modes

- Generate generic classifier/router wrappers.
- Make the provider brand the product thesis.
- Assume AI is necessary because the conversation began with AI.
- Ignore cheaper deterministic or local alternatives.

## Expected behavior

1. Characterize the new capability regime: latency, cost, structure, privacy, reliability.
2. Explore interaction classes that were previously impractical.
3. Map those capabilities onto valuable user workflows and intervention points.
4. Run the technology-off test: does the user outcome still matter without the named provider?
5. Run the substitution test against deterministic code, local models, general models, and human confirmation.
6. Keep the technology as CORE, ENABLING, ENHANCING, or UNNECESSARY.

## Regression rules added

- **Technology-off test.**
- **Substitution test.**

## Pass condition

The result contains user-value hypotheses enabled by the technology, not a list of technology wrappers.
